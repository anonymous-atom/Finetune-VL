# Research Question Evaluation Arena

This Space hosts an interactive evaluation platform for comparing AI-generated research questions. Users can:

- View research paper pages
- Compare questions generated by different AI models
- Rate questions based on various metrics
- Vote on the best questions

## Usage

1. The interface will show you a research paper and three AI-generated questions
2. Read through the paper and questions carefully
3. Rate each question based on the provided metrics
4. Select the best question or indicate if they're equally good
5. Submit your evaluation to get a new sample

## Metrics

Questions are evaluated on:
- Clarity
- Relevance
- Depth
- Originality
- Usefulness
- Discussion Potential
- Understanding Check

## Data Storage

All evaluations are stored locally in CSV format for analysis

## Features

- Compare questions from multiple AI models side by side
- Rate questions on multiple dimensions:
  - Essential Qualities: Clarity, Relevance, Depth, Originality
  - Research Impact: Usefulness, Discussion Potential, Comprehension Check
- Simple and intuitive interface for evaluation
- Automatic data collection for research analysis

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python src/app.py
```

## Data Structure

The evaluation data is stored in CSV format with the following columns:
- session_id: Unique identifier for each evaluation session
- timestamp: When the evaluation was made
- sample_id: Identifier for the paper being evaluated
- Response 1/2/3: Model names for each response
- winner: Which response was selected as best
- tie: Whether there was a tie
- Various rating metrics (1-5 scale)
